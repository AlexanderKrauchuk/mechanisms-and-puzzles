# Механизмы и загадки

Модуль интерактивных головоломок для Foundry Virtual Tabletop 13.

Модуль разрабатывается без привязки к игровой системе.
Целевая среда использования — Foundry VTT 13, в том числе на Forge VTT.

## Текущее состояние

Версия 0.1.0 — начальный каркас модуля.

Реализовано:
- регистрация модуля;
- русская локализация;
- окно управления для мастера;
- отображение версии Foundry, игровой системы и текущей сцены.

Пока не реализованы:
- создание и хранение загадок;
- пятнашки, поворотные кольца и последовательности символов;
- взаимодействие игроков;
- привязка к объектам сцены;
- действия при успехе и провале.

## Установка

В интерфейсе установки модулей используйте Manifest URL:

https://raw.githubusercontent.com/AlexanderKrauchuk/mechanisms-and-puzzles/main/module.json

Для установки должен быть опубликован релиз с ZIP-архивом,
указанным в поле download файла module.json.

После установки включите модуль в настройках мира.

## Открытие окна управления

Войдите мастером и откройте:

Настройки игры → Настроить параметры →
Механизмы и загадки → Управление загадками.

## Совместимость

- Целевая версия: Foundry VTT 13.
- Модуль не зависит от конкретной игровой системы.
- Специальная поддержка мобильных устройств не предусмотрена.
