# Журнал изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии нумеруются по [SemVer](https://semver.org/lang/ru/).

## [Не выпущено]

### Добавлено
- Контракт типа головоломки и реестр типов (`scripts/puzzles/base.mjs`).
- Головоломка «последовательность символов»: режимы проверки `step` и `final`, поведение при ошибке `reset`, `ignore` и `fail`.
- Движок на стороне мастера: создание, сброс, проверка ходов по очереди, событие `mechanisms-and-puzzles.outcome`.
- Окно загадки для игрока (ApplicationV2), обновляется при изменении состояния.
- Тесты логики и движка, запуск тестов в CI.
- API для макросов: `engine.createPuzzle`, `engine.resetPuzzle`, `openPuzzle`, `listPuzzles`.
- Документация: инструкция по установке на The Forge.
- Головоломка «пятнашки»: поле от 2×2 до 6×6 (не обязательно квадратное), ходы только в соседнюю пустую клетку, счётчик ходов.
- Перемешивание пятнашек с гарантией решаемости: все решаемые расположения равновероятны, поле никогда не стартует решённым.
- Подсветка плиток, которые можно сдвинуть, в окне игрока.
- Тесты пятнашек: формула решаемости сверена с полным перебором достижимых состояний (2×2, 2×3, 3×2, 2×4, 3×3).
- Головоломка «поворотные кольца»: 1-5 колец, 2-12 секторов, свои подписи секторов, проверка после каждого поворота или по кнопке, провал при неверной проверке, отрисовка в SVG.
- Окно управления мастера: список загадок сцены, создание, изменение, сброс, удаление с подтверждением, показ решения, кнопка «Почти решить (тест)» для проверки успеха, блок диагностики.
- Редактор загадок для всех трёх типов с проверкой введённых данных.
- Три способа открыть окно управления: кнопка в панели инструментов, пункт в настройках модуля, `api.openManager()`.
- Методы движка `updatePuzzle`, `deletePuzzle`, `nearSolve`, `getForEdit`.
- Тесты колец, редактора и новых методов движка (всего 82).
- README: пошаговый чек-лист проверки мастером внутри Foundry.

- Привязка загадки к токену или плитке сцены (кнопки «Взять выбранный токен/плитку» в редакторе, «Показать на сцене» в окне мастера).
- Проверка расстояния до привязанного объекта на стороне мастера (по прямой, край до края, в единицах сцены) и режим «выключена для игроков».
- Окно «Загадки рядом» для игроков (кнопка в панели слева, `api.openList()`), подсказка о недоступности в окне загадки, пересчёт при перемещении токенов и плиток.
- Коды ответа игроку `off`, `tooFar`, `noToken`, `noObject`.
- Тесты доступа и расстояния (всего 101).

### Изменено
- Запросы к мастеру получают признак `local`: поблажки мастеру (без проверки расстояния и режима) действуют только для запросов с его же клиента, а не для сообщений сокета с его userId.
- Вместо поля `linkedUuid` загадка хранит `link: { kind, id }`; старые данные читаются без ошибок.
- Контракт типа головоломки: `initialState(config, secret)` получает секрет, чтобы начальное состояние не совпало с решением.

## [0.1.0]

### Добавлено
- Каркас модуля для Foundry v13: манифест, русская локализация, настройки.
- Хранилище загадок: публичные данные во flags сцены, секреты в скрытом журнале.
- Канал «игрок → мастер» через сокет с таймаутом и обработкой отсутствия мастера.
- Настройка запуска макросов (по умолчанию выключена) с предупреждением.
- Диагностика `api.verifySecrecy()` и проверочный запрос `ping`.
- Репозиторий: CI-проверки и автоматическая сборка релиза.
