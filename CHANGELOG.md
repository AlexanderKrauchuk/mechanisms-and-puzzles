# Журнал изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии нумеруются по [SemVer](https://semver.org/lang/ru/).

## [Не выпущено]

### Добавлено
- Контракт типа головоломки и реестр типов (`scripts/puzzles/base.mjs`).
- Головоломка «последовательность символов»: режимы проверки `step` и `final`, поведение при ошибке `reset`, `ignore` и `fail`.
- Движок на стороне мастера: создание, сброс, проверка ходов по очереди, событие `mechanisms-and-puzzles.outcome`.
- Окно загадки для игрока (ApplicationV2), обновляется при изменении состояния.
- Тесты логики и движка, запуск тестов в CI.
- API для макросов: `engine.createPuzzle`, `engine.resetPuzzle`, `openPuzzle`, `listPuzzles`.
- Документация: инструкция по установке на The Forge.
- Головоломка «пятнашки»: поле от 2×2 до 6×6 (не обязательно квадратное), ходы только в соседнюю пустую клетку, счётчик ходов.
- Перемешивание пятнашек с гарантией решаемости: все решаемые расположения равновероятны, поле никогда не стартует решённым.
- Подсветка плиток, которые можно сдвинуть, в окне игрока.
- Тесты пятнашек: формула решаемости сверена с полным перебором достижимых состояний (2×2, 2×3, 3×2, 2×4, 3×3).

## [0.1.0]

### Добавлено
- Каркас модуля для Foundry v13: манифест, русская локализация, настройки.
- Хранилище загадок: публичные данные во flags сцены, секреты в скрытом журнале.
- Канал «игрок → мастер» через сокет с таймаутом и обработкой отсутствия мастера.
- Настройка запуска макросов (по умолчанию выключена) с предупреждением.
- Диагностика `api.verifySecrecy()` и проверочный запрос `ping`.
- Репозиторий: CI-проверки и автоматическая сборка релиза.
